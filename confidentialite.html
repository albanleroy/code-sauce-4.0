Code Sauce — règles de confidentialité

Code Sauce est un jeu de quiz privé, développé à titre personnel par Alban Leroy et réservé aux personnes qu'il autorise. Il n'y a ni publicité, ni revente, ni partage de données avec qui que ce soit.

Connexion avec Google

Quand tu te connectes avec Google, Google transmet à Code Sauce une preuve signée de ton adresse e-mail. Code Sauce ne garde que cette adresse, pour savoir qui demande l'accès. Ton nom et ta photo Google ne sont pas conservés, et Code Sauce n'a jamais accès à ton mot de passe Google ni à tes autres données Google.

Ce que Code Sauce conserve

  • ton adresse e-mail, ton pseudo, et l'avatar, la bannière et la couleur que tu choisis ;
  • tes parties, statistiques et progrès d'apprentissage, tes amis et tes groupes ;
  • pour chaque appareil autorisé : sa clé publique, le nom de l'appareil et les dates d'accès. La clé privée ne quitte jamais ton appareil.

Ces données servent uniquement à faire fonctionner le jeu. Elles sont stockées sur un serveur personnel en France. Les journaux techniques du serveur peuvent contenir ton adresse lors d'une demande d'accès.

Hébergement et transport

Le site passe par un tunnel Cloudflare et ses pages d'accès sont hébergées par GitHub Pages ; ces services voient passer les connexions comme pour tout site qu'ils servent.

Suppression

Tu peux demander à tout moment la suppression de ton compte et de toutes ses données : contacte directement l'administrateur de Code Sauce. Tu peux aussi retirer l'accès de Code Sauce depuis ton compte Google (Sécurité → Applications tierces).
